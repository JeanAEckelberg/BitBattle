## Submission

> An individual instance of a bot (the code) written by a competitor, as uploaded and submitted to the tournament.

### Test Submission

> An individual instance of a bot (the code) as written by a competitor, as uploaded to the tournament, viewed, and deleted.

### Active Submission

> A submission which is currently running in tournament cycles and available to test against other active submissions

## Match

> An individual run of a game between two specific submissions.

## Tournament

> A set of matches complete with each competitor's (active? current?) submission, ran against as many other (active? current?) submissions as tournament structure demands.

## Action

> A game "action" that can be taken by a bot within a match. e.g. "Move Left", "Jump", "Attack"...

## Game

> The "game" which the competition designers built for use by bots. If you were given a normal set of controls, you could play it as you would any normal video game.

## Tick

> The singular turnover of the game running over the state of the game and processed actions and triggers.

## Turn

> A tick at which a bot is given the chance to take an action.
